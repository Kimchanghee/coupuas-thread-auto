# UI/UX 개선 적용 기록

2026-09-08. 승인된 검토 내용을 실제 Python/PyQt 화면과 동작에 반영했다.

| 검토 항목 | 적용 내용 |
|---|---|
| F01 재시도 계정 | 원 계정을 확인·선택한 뒤 해당 초안에 추가. 원 계정이 없으면 중단하고 중복 추가 방지 |
| F02 실행 범위 | 전체 대기열 실행으로 명칭 변경. 계정별 수량·간격 확인 후 실행. 개별 실행은 계정·유효 링크·제외 수량, 저장 대기열 재개도 대상 확인 |
| F03 연결 상태 | 최근 성공, 오래됨, 미확인, 실패를 분리. 실패 상태와 확인 시각 저장. 최근 성공 기준 24시간 |
| F04 구독 정보 | 이용 만료와 다음 결제일을 별도 표시. 없는 결제일·수단을 추정하지 않고 결제 관리로 안내 |
| F05 짧은 창 | 진행 단계 한 줄, 실행 중 입력 접기·펼치기, 상태 우선 배치로 표 공간 확보 |
| F06 좁은 표 | 원본 URL 열 유지. 클릭·Enter로 상세, 원본 복사·상품 링크 열기 |
| F07 상태 대비 | 밝은 배경용 진한 성공·경고·오류 텍스트, 업데이트 어두운 패널용 밝은 상태색 |
| F08 글꼴 | Pretendard Regular·Medium 추가. 지표 28px, 설명 13px. 기존 제목·본문 계층 유지 |
| F09 탐색 | 홈·자동화·기록·계정·설정·구독 라벨. 넓은 메뉴와 화면 머리말에 벡터 아이콘. 기존 단축키 유지 |
| F10 운영 집계 | 저장된 이력에서 오늘 결과 집계. 집계 전과 기록 조회 실패 구별. 확인된 계정 수와 전체 연결 수 구분 |
| F11 기록 상세 | 계정·시간·결과·사유·원본 URL 상세. 검증된 Threads 게시물 URL이 있는 경우에만 게시물 버튼 표시. 좁은 집계·필터 압축 |
| F12 설정 범위 | 간격은 현재 계정, 나머지는 공통임을 명시. 편집 계정 표시와 저장 결과에 대상·적용 시점 안내 |
| F13 설정 경로 | 폼 폭 800px 제한. 계정 추가·설정 경로 명확화. 결제 입력은 기존 결제 설정 화면으로 연결. 미저장 표시·취소·저장 결과 |
| F14 복구 동작 | 세션 만료 시 해당 계정 연결. 오류 확인 후 재시도. 게시 불확실 항목 확인 안내, 오프라인 자동 재개 설명, 완료 성공·실패 수량 |
| F15 로그인·가입 | 비밀번호 보기·숨기기와 Caps Lock 안내. 오류 필드 포커스. 가입 단계 버튼을 스크롤 밖 하단에 고정 |
| F16 시작 안내 | 테스트 링크 버튼 아래 실제 게시하지 않는다는 안내 추가. 기존 진행 상태 보존·돌아오기 흐름 유지 |
| F17 업데이트 | 최신/확인 실패 전환 시 이전 파일 크기 제거. 다운로드 중 닫기는 창만 닫고 계속 진행됨을 안내 |
| F18 웹사이트 | 존재하지 않는 문안 수동 선택 안내를 실제 자동 생성 흐름에 맞게 수정 |

## 검증

- 관련 회귀 테스트 110개 통과. 계정·대기열·로그인·구독·업데이트·온보딩·반응형 화면 포함.
- 소스 컴파일 및 `python tools/sanity_check.py` 통과.
- 실제 Qt 위젯을 사용하는 오프라인 QA 화면 61장 생성 및 주요 화면 시각 검사.
- 760×560, 900×620, 1360×900 × 6개 화면 × 100/150/200% 배율: 54조건 텍스트 맞춤 검사.
- 화면 자료: `tmp/uiux-applied`. 테스트 결과: `tmp/uiux-all-tests.txt`.
- QA 화면은 가상 데이터이며 실제 게시·결제·계정 삭제는 실행하지 않았다. 서버가 제공하지 않는 결제 필드는 UI에서 미제공으로 표시한다.
- 로컬 소스 수정본 기준이다. 배포 설치 파일 생성·공개 사이트 배포는 별도다.
