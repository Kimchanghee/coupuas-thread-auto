## Store listing (ko-KR)

### Product name

Thread Auto

### Short description

쇼핑 제휴 링크를 분석해 채널별 콘텐츠를 만들고 여러 Threads 계정의 게시 흐름을 한곳에서 관리하는 Windows 데스크톱 앱입니다.

### Description

Thread Auto는 쇼핑 제휴 콘텐츠 운영자가 상품 링크 확인부터 문안 생성, Threads 게시 준비까지 반복되는 작업을 한곳에서 관리하도록 돕는 Windows 앱입니다.

쿠팡뿐 아니라 네이버 쇼핑커넥트, AliExpress, Temu, 오늘의집, 무신사, 컬리 등 지원 채널의 링크를 분류하고 상품 정보를 확인합니다. 사용자가 선택한 AI 방식으로 여러 문안 후보를 만들고, 계정별 대기열과 작업 기록을 통해 게시 흐름을 정리할 수 있습니다.

브라우저 로그인 세션과 앱 설정은 사용자 PC를 중심으로 저장합니다. 서버 요청은 로그인 토큰으로 인증하며 작업량은 예약, 확정, 해제 흐름으로 안전하게 처리합니다.

앱 다운로드는 무료이며 계정을 만들면 매월 자동화 작업 5회를 무료로 사용할 수 있습니다. 무료 계정은 Threads 계정 1개를 연결할 수 있고, 매월 첫 번째 성공 작업 1회에 한해 지원되는 모든 쇼핑 채널 링크를 체험할 수 있습니다. 그 이후 남은 무료 작업 4회는 쿠팡 링크만 지원합니다. 월 무료 작업 5회를 모두 사용하면 다음 월 초기화까지 기다리거나 별도 이용권을 구매해야 새 문안 생성과 게시 자동화를 계속할 수 있습니다.

일부 고급 기능은 별도 이용권이 필요할 수 있으며, 앱 결제 화면에서 기간·가격·지원 채널·연결 가능한 Threads 계정 수를 확인할 수 있습니다. Threads 게시 기능을 사용하려면 사용자가 자신의 Threads 계정으로 로그인해야 합니다.

AI가 생성한 문안이 유해하거나 부적절하거나 사실과 다를 경우 앱의 `설정 → AI · 앱 → 부적절한 AI 결과 신고하기`에서 신고할 수 있습니다. 게시물 내용과 개인정보는 자동으로 전송되지 않으며, 사용자가 이메일에 직접 입력한 내용만 고객지원 담당자에게 전달됩니다.

## Certification notes (ko-KR)

앱 실행 후 회원가입 화면에서 새 계정을 만들 수 있습니다. 무료 계정에는 기본 작업량이 제공되므로 결제 없이 링크 분류와 문안 생성 흐름을 확인할 수 있습니다. 실제 Threads 게시는 심사자가 소유한 Threads 계정 로그인이 필요합니다. 외부 계정 로그인을 원하지 않는 경우 링크 입력, 채널 분류, 설정, 대기열 구성까지 검증할 수 있습니다.

정책 11.16 확인 경로: `설정 → AI · 앱 → 부적절한 AI 결과 신고하기`. 전용 버튼은 AI 생성 결과 신고 이메일을 열며 앱 버전과 선택한 AI 방식만 미리 채웁니다. 생성된 문안, 링크, 계정 정보와 개인정보는 자동 첨부하거나 전송하지 않습니다.

정책 10.8.4 무료 이용 제한: 무료 계정은 매월 작업 5회와 Threads 계정 1개를 사용할 수 있습니다. 월 첫 번째 성공 작업 1회만 모든 지원 쇼핑 채널 링크를 체험할 수 있고, 나머지 무료 작업 4회는 쿠팡 링크만 지원합니다. 5회를 모두 사용하면 다음 월 초기화 또는 별도 이용권이 필요합니다.

패키지는 Microsoft Store 배포 모드에서 자체 EXE 업데이트를 사용하지 않으며 Store 업데이트를 따릅니다. 브라우저 세션과 앱 설정은 사용자 PC에 저장됩니다. 개인정보처리방침과 고객지원 페이지는 위 URL에서 로그인 없이 확인할 수 있습니다.
