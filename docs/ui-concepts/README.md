# 스레드 쇼핑 자동화 UI 시안 5종

운영 코드에 적용하기 전에 톤, 정보 밀도, 반응형 구조를 비교하기 위한 정적 프로토타입입니다.

## 시안

1. **Midnight Ledger** — 기존 다크 브랜드를 유지하면서 위계와 가독성을 정돈한 추천안
2. **Fluent Canvas** — Windows 데스크톱에 익숙한 밝은 생산성 도구
3. **Signal Control** — 다계정·다링크 상태를 빠르게 판독하는 관제형
4. **Coral Focus** — 한 번에 한 단계에 집중해 초보자 실수를 줄이는 흐름
5. **Nordic Bento** — 노트북부터 울트라와이드까지 확장되는 12열 대시보드

브라우저에서 `index.html`을 열고 상단 버튼 또는 `Alt+1`~`Alt+5`로 전환합니다. 캡처용 주소는 `?concept=1&clean=1` 형식입니다.

## 공통 반응형 규칙

- Qt의 물리 픽셀이 아닌 논리 픽셀(DIP) 기준, 네이티브 DPI 스케일링 유지
- 최소 지원 폭 760, compact 760–959, standard 960–1439, wide 1440 이상
- 4px 간격 토큰, 화면 거터 16/24/32px, 콘텐츠 최대 폭 1440px
- 입력·핵심 버튼 높이 최소 44px, 아이콘 버튼 36–40px, 표 필터는 28–32px
- 본문 15–16px(데스크톱 이식 시 10.5–11pt), 보조문도 12px 미만으로 축소하지 않음
- 고정 폭은 아이콘·작은 배지에만 사용하고 주요 패널은 min/max와 유동 그리드로 배치
- 960 미만에서 실행 요약은 메인 아래로 이동하고 사이드바는 아이콘 레일로 축소
- 화면 높이 760 미만에서는 설명문과 여백을 줄이되 주요 조작과 표는 유지

## 오픈소스 참고

- shadcn/ui, Radix Primitives: 접근성 기본값, 단순한 카드/탭 위계
- Material UI: 밝은 화면의 표면 레벨과 익숙한 조작 패턴
- Ant Design: 데이터 밀도와 표/상태 표시
- Fluent UI: Windows 생산성 도구의 내비게이션과 계정 영역
- Lucide: 24px 선형 아이콘 규칙

프로덕션이 PyQt6이므로 React 컴포넌트 코드를 직접 포함하지 않고, MIT/ISC 프로젝트의 공개 디자인 원칙을 Qt 컴포넌트 토큰으로 번역합니다. PyQt-Fluent-Widgets는 GPLv3/상용 라이선스 조건 때문에 직접 의존하지 않습니다.
