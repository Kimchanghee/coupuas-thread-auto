## 판정 주의사항

공개 프로필이 없더라도 다음 상황에서는 아이디 저장이 거부될 수 있다.

- 비공개, 비활성, 정지된 계정이 아이디를 보유한 경우
- 탈퇴 계정 아이디를 플랫폼이 일정 기간 예약한 경우
- 상표, 사칭 방지 또는 내부 예약어로 분류된 경우
- 새 Facebook 페이지에 사용자명 생성 제한이 적용된 경우
- Naver에서 탈퇴된 아이디를 재사용할 수 없는 경우

따라서 현재 판정은 `공개 충돌 없음`이다. 최종 확정은 각 로그인 계정의 사용자명 입력란에 `shortsthreadmaker`를 넣고 사용 가능 표시를 확인한 뒤 저장해야 한다.

1순위가 내부 예약 등의 이유로 한 플랫폼에서만 거부될 때 다음 순서로 사용한다.

| 순위 | 아이디 | 장점 | 단점 |

| 2 | `shortsthreadlab` | 짧고 콘텐츠 실험실 느낌 | 현재 제품명과 완전히 같지는 않음 |
| 3 | `shortsthreadmakerkr` | 브랜드 유지, 한국 계정 구분 | 길고 해외 확장에 불필요한 `kr` 포함 |
| 4 | `ssmakerlab` | 매우 짧음 | 처음 보는 사람이 의미를 알기 어려움 |

한 플랫폼에서만 충돌해도 가능한 한 전체 채널을 동일한 대체 후보로 변경한다. 플랫폼마다 서로 다른 숫자나 밑줄을 붙이지 않는다.

## 최종 확보 순서

1. Instagram에서 `shortsthreadmaker` 저장 가능 여부를 확인한다.
2. 연결된 Threads에서도 동일 아이디를 확인한다.
3. TikTok과 YouTube 핸들을 즉시 확보한다.
4. Facebook Page 사용자명을 저장한다.
5. Naver ID를 마지막으로 가입한다.
6. 모든 계정에 동일한 프로필 사진, 표시 이름, 소개 링크를 적용한다.

아이디를 실제 저장하기 직전에는 기존 아이디를 다시 얻지 못할 수 있으므로 계정별 변경 대상을 한 번 더 확인한다.
