# Thread Auto UI/UX 개선 적용 · 2026-09-13

승인된 `Thread_Auto_UIUX_Refinement_Appllama_20260913.pdf`를 바탕으로 기존 PyQt6 앱과 공개 웹 화면을 다듬었습니다. 기존 사이드바, 아이보리 배경, 청록색 강조, 계정별 초안 구조를 유지하면서 실행 대상과 다음 행동이 더 분명하게 보이도록 변경했습니다.

## 적용 내용

| 영역 | 반영한 동작 |
|---|---|
| 운영 홈 | 새 자동화 버튼을 중심으로 정리하고, 계정 미연결·재확인 필요·정상 상태에 따라 다음 안내를 변경합니다. 주의 계정 확인 버튼은 해당 계정으로 이동합니다. |
| 자동화 | 상단에 게시 계정과 연결 상태, 실행 전 패널에 사용 가능·제외 링크 수와 게시 간격을 표시합니다. 단일 계정의 불필요한 탭 공간을 줄이고 전체 대기열 실행을 보조 행동으로 구분합니다. |
| 화면 복귀 | 문맥 이동 시 ‘이전 작업으로’와 Alt+Left로 원래 페이지·계정·설정 탭·초점에 돌아갑니다. 기존 계정 전환 경로를 사용하며, 미저장 설정을 버리는 복귀는 확인을 거칩니다. |
| 작업 기록 | 집계를 한 줄로 정리하고 행을 누르면 상세를 엽니다. 로그인·세션 오류는 계정 확인으로 연결합니다. 새 기록이 들어와도 같은 항목의 선택을 유지하도록 표시 식별자를 안정화했습니다. |
| Threads 계정 | 계정명·사용자 이름·상태의 잘림을 줄였습니다. 연결 확인을 우선 행동으로, 재로그인과 정보 수정을 보조 행동으로 정리했습니다. |
| 설정 | 현재 편집 계정과 계정별/공통 설정 범위를 안내합니다. 계정 관리와 기존 설정 편집기를 연결합니다. |
| 구독·지원 | 넓은 화면은 비교표, 좁은 화면은 세로 카드로 표시합니다. 월간·7일 상품이 함께 있으면 기간을 선택합니다. 수동 선택은 새로고침에도 유지하고 실제 이용권 변경은 반영합니다. |
| 로그인·가입 | 관련 입력칸 아래 오류를 표시하고 다시 입력하면 안내를 지웁니다. 브랜드 패널의 숫자는 사용 단계 01–03으로 바꿨습니다. |
| 도움말 | 닫으면 기존 입력 컨트롤로 키보드 초점을 돌려줍니다. |
| 공개 웹 | 청록색 강조와 Thread Auto 명칭을 맞추고 다운로드 후 설치·가입·연결 순서를 안내합니다. 모바일 상단 다운로드 버튼의 대비와 줄바꿈을 수정했습니다. |
| 비밀번호 복구 | 요청·변경 완료 후 다음 행동을 안내하고 완료 영역으로 키보드 초점을 이동합니다. |

Appllama의 정보 위계, 명확한 주 행동, 상태별 안내, 돌아올 수 있는 탐색 원칙을 기존 데스크톱 구조에 맞춰 적용했습니다. 원본 스킬은 [Appllama skills](https://github.com/Appllama/appllama-skills)입니다. Appllama MCP를 통한 벤치마크 화면 수집은 수행하지 않았습니다.

## 검증

- Python 회귀 테스트 102개 통과: 반응형 화면, 계정 이동, 초안 관련 기존 동작, 결제 연결, 로그인, 설정, 작업 기록, 추가한 개선 동작.
- Node 테스트 66개 통과.
- 변경 Python 파일 구문 검사와 `git diff --check` 통과.
- 실제 Qt 위젯을 이용해 63개 오프라인 화면을 캡처했습니다. 넓은/좁은 화면과 주요 상태에서 대표 캡처의 한글, 겹침, 잘림을 확인했습니다.
- Playwright에서 공개 웹 1440px·390px·320px 너비와 복구 완료 화면을 확인했습니다. 수평 넘침이 없고 완료 영역의 초점 이동이 동작했습니다.
- 복구 요청은 로컬 모의 응답을 사용했습니다. 정적 로컬 서버의 `/api/notices` 미제공으로 발생한 404는 실제 배포 API 검증 결과가 아닙니다.
