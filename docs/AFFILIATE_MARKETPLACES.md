# 제휴 링크 지원 안내

Thread Auto는 사용자가 각 제휴 프로그램에서 이미 발급받은 상품 링크를 Threads 콘텐츠에 활용하도록 돕습니다. 제휴 프로그램 가입·승인, 링크 발급, 수수료 정산은 각 운영사의 서비스에서 직접 진행해야 합니다.

## 지원 범위

| 프로그램 | Thread Auto 이용권 | 알려진 입력 도메인 |
| --- | --- | --- |
| 쿠팡 파트너스 | 쿠팡 기본 또는 쇼핑 프로 | `coupang.com`과 하위 도메인 |
| 네이버 쇼핑 커넥트 | 쇼핑 프로 | `shopping.naver.com`, `smartstore.naver.com`, `brand.naver.com`, `shoppinglive.naver.com`, `brandconnect.naver.com`, `naver.me` |
| 토스 쇼핑 쉐어링크 | 쇼핑 프로 | `shopping.toss.im`, `shopping-view.toss.im`, `link.toss.im`, `toss.im`, `toss.shopping` |
| 오늘의집 큐레이터 | 쇼핑 프로 | `ozip.me`, `link.ohou.se`, `ohou.se`, `store.ohou.se` |
| 무신사 큐레이터 | 쇼핑 프로 | `musinsa.com`, `musinsa.onelink.me` |
| 컬리 큐레이터 | 쇼핑 프로 | `kurly.com`, `lounge.kurly.com` |
| 올리브영 쇼핑 큐레이터 | 쇼핑 프로 | `oy.run`, `m.oliveyoung.co.kr`, `www.oliveyoung.co.kr` |
| AliExpress | 쇼핑 프로 · 호환 지원 | `aliexpress.com`과 하위 도메인 |

AliExpress는 국내 7개 제휴 프로그램과 별개의 호환 대상입니다. 쿠팡 파트너스 외 모든 입력은 쇼핑 프로 이용권 또는 해당 체험 권한이 필요합니다.

## 링크를 입력하기 전에

1. 해당 제휴 프로그램에 가입하고 승인을 완료합니다.
2. 운영사 화면에서 본인에게 귀속된 제휴 링크를 발급받습니다.
3. Thread Auto의 **링크 입력** 화면에 한 줄에 하나씩 붙여넣습니다.

일반 상품 페이지를 입력했다고 해서 Thread Auto가 제휴 코드나 추적 파라미터를 추가하지는 않습니다. 수수료 귀속 여부는 반드시 발급한 서비스에서 먼저 확인하세요.

## 원본 제휴 URL 보존

Thread Auto는 사용자가 입력한 원본 제휴 URL을 Threads 게시물의 상품 링크로 유지합니다. 상품 정보를 확인하는 과정에서 단축 URL의 도착 페이지를 임시로 조회할 수 있지만, 분석된 최종 URL로 게시 링크를 교체하지 않습니다. 이 방식은 원본 링크에 들어 있는 제휴 식별자와 추적 정보를 보존하기 위한 것입니다.

단, 운영사가 발급 링크를 만료·회수하거나 리다이렉트 정책을 변경한 경우에는 원본 링크를 유지해도 정상적인 수수료 귀속을 보장할 수 없습니다. 게시 전후에 각 제휴 프로그램의 관리 화면에서 링크 상태를 확인하세요.

## 공개 메타데이터와 리다이렉트 제한

상품명, 설명, 이미지 후보 등은 로그인 없이 접근 가능한 공개 상품 페이지와 공개 메타데이터에서 가져옵니다. 다음 상황에서는 일부 정보가 비어 있거나 링크 분석이 실패할 수 있습니다.

- 로그인, 성인 인증, 지역 확인 또는 모바일 앱 실행이 필요한 페이지
- 로봇 차단, 일시적인 접속 제한, 삭제·품절·비공개 상품
- JavaScript 실행 후에만 상품 정보가 표시되는 페이지
- 아직 지원 목록에 없는 새 단축 도메인이나 URL 형식
- 해당 쇼핑몰의 허용된 공개 도메인 밖으로 이동하는 리다이렉트
- 리다이렉트가 너무 많거나 순환하는 링크

보안을 위해 Thread Auto는 확인된 쇼핑몰의 허용된 HTTPS 도메인 안에서만 리다이렉트를 따라갑니다. 분석이 실패하면 제휴 프로그램에서 링크를 다시 발급받거나, 로그인 없이 브라우저에서 열리는지 확인한 뒤 다시 시도하세요.

## 제휴 고지

Thread Auto는 판별된 프로그램에 맞는 광고·제휴 고지를 문안에 포함합니다. 게시 책임은 사용자에게 있으므로 발행 전에 문구가 최신 운영사 정책과 관련 법령에 맞는지 확인하고, 필요한 경우 운영사가 안내한 표현으로 수정하세요.
