개인정보처리방침

서비스에 필요한 정보만 처리하고, Threads 로그인 세션은 사용자 PC를 중심으로 보관합니다.

시행일 2026년 8월 2일

1. 처리하는 정보와 목적

회원 정보
회원가입·로그인, 계정 식별, 보안 알림과 고객지원
결제 정보
휴대폰 번호, 결제·구독 식별자, 승인 상태와 이용 기간을 결제 및 권한 부여에 사용
서비스 이용 기록
작업량, 요청 식별자, 오류·보안 로그를 중복 차감 방지, 품질 개선과 부정 이용 방지에 사용
AI 요청 정보
회원이 입력한 상품명·특징·링크 등 문안 생성에 필요한 내용을 결과 생성에 사용
웹 이용 정보
페이지 조회와 다운로드 클릭 등 최소한의 통계정보를 사이트 개선에 사용

2. 보유와 파기

  • 회원·구독 정보는 회원 탈퇴 또는 처리 목적 달성 시까지 보유하며, 관계 법령상 보존 의무가 있는 거래 기록은 정해진 기간 동안 분리 보관할 수 있습니다.
  • 보안·오류 기록은 부정 이용 대응과 장애 분석에 필요한 합리적인 기간만 보유합니다.
  • 보유 목적이 끝난 전자정보는 복구가 어렵도록 삭제하거나 비식별 처리합니다.

3. 제3자 제공과 처리위탁

회사는 서비스 제공에 필요한 범위에서 다음 사업자의 시스템을 이용합니다.

PayApp·유디아이디
결제 요청, 승인·정기결제 및 결제 상태 처리
Supabase
회원, 인증, 구독·작업량 데이터 저장
Vercel
웹사이트·관리형 AI API 제공 및 접속 통계
AI 모델 공급자
상품 정보를 바탕으로 문안 후보 생성
GitHub
프로그램 배포, 공지 원문과 고객지원 이슈 관리

고객지원 이슈는 공개될 수 있으므로 비밀번호, 로그인 토큰, 결제정보, 전화번호 등 민감한 정보는 GitHub에 작성하지 마세요. 개인정보 관련 요청은 아래 이메일을 이용해 주세요.

4. 로컬에 저장되는 정보

Threads 브라우저 세션, 앱 설정, 계정별 대기열과 재개 상태는 원칙적으로 사용자의 PC에 저장됩니다. 프로그램은 운영체제의 보호 기능과 제한된 파일 권한을 사용하지만, 공용 PC에서는 사용 후 로그아웃하고 Windows 계정을 안전하게 관리해야 합니다.

5. 이용자의 권리

이용자는 자신의 개인정보에 대해 열람, 정정, 삭제, 처리정지 및 동의 철회를 요청할 수 있습니다. 본인 확인이 필요한 경우 최소한의 확인 절차를 거칩니다.
