Getting started

구매·이용 안내

별도 AI API 키 없이, 제휴 프로그램에서 발급받은 링크를 붙여넣어 시작할 수 있습니다.

Windows 10·11 지원

1. 설치하고 무료로 확인하기

  1. 공식 GitHub Release의 설치 파일을 다운로드합니다.
  2. 설치 파일의 게시자와 디지털 서명을 확인하고 설치합니다.
  3. 앱에서 회원가입·로그인하면 매월 5회 무료 작업이 제공됩니다.
최신 Windows 설치 파일

2. 유료 이용권 결제

  1. 앱의 설정 → 구독 · 지원을 엽니다.
  2. 쿠팡 기본 또는 쇼핑 프로, 7일 일회결제 또는 월간 정기결제를 선택합니다.
  3. 휴대폰 번호를 입력하고 PayApp 보안 결제창에서 승인합니다.
  4. 앱의 결제 상태 새로고침을 누르면 서버에 적용된 이용권을 확인할 수 있습니다.

쿠팡 파트너스 외 6개 국내 제휴 프로그램과 AliExpress 호환 링크를 사용하려면 쇼핑 프로를 선택하세요. 다른 월간 요금제로 전환할 때에는 기존 정기결제를 먼저 해지해야 중복 결제를 방지할 수 있습니다.

3. 제휴 링크 준비와 지원 범위

쿠팡 파트너스·네이버 쇼핑 커넥트·토스 쇼핑 쉐어링크·오늘의집 큐레이터·무신사 큐레이터·컬리 큐레이터·올리브영 쇼핑 큐레이터에서 이미 발급받은 제휴 링크를 한 줄에 하나씩 붙여넣으세요. AliExpress는 기존 사용자를 위한 호환 대상으로 지원합니다. Thread Auto는 프로그램 가입·승인이나 제휴 링크 발급·전환을 대신하지 않습니다.

게시물에는 제휴 식별 정보가 담긴 원본 입력 URL을 유지합니다. 상품명과 특징은 로그인 없이 확인되는 공개 메타데이터와 해당 쇼핑몰에 허용된 리다이렉트만 사용해 분석합니다. 앱·로그인 전용 페이지, 차단된 요청, 새 단축 도메인 또는 허용 범위 밖으로 이동하는 리다이렉트에서는 상품 정보가 일부 누락되거나 분석이 실패할 수 있습니다.

4. 업데이트

새 버전이 공개되면 실행 시 업데이트 알림이 표시됩니다. 작업 중이라면 안전하게 중단 상태를 저장하고 업데이트한 뒤 프로그램을 다시 실행해 이어서 처리합니다. 설치 파일과 체크섬은 공지사항과 GitHub Release에서 확인할 수 있습니다.

5. 문제 해결

로그인 만료
앱에서 다시 로그인하세요.
결제 미반영
결제 승인 여부를 확인한 뒤 구독 상태를 새로고침하세요.
링크 분석 실패
발급 링크가 로그인 없이 열리는지 확인하고, 제휴 프로그램에서 다시 발급받아 시도하세요.
업로드 실패
해당 Threads 계정의 로그인 상태와 대기열 로그를 확인하세요.
설치 경고
공식 Release에서 받았는지, 코드 서명과 SHA-256 체크섬이 일치하는지 확인하세요.
