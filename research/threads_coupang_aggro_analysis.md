# 스레드(Threads) 쿠팡파트너스 어그로 글 패턴 분석

> 조사일: 2026-06-03 · 표본: Threads 검색 "쿠팡파트너스" / "쿠파스" (인기·최근 탭) · 실제 게시물 30+ 개(1차 본문 + 2차 연결글/댓글) 직접 수집
> 목적: 어그로(후킹) 1차 본문과 상품을 배치하는 2차 댓글의 구조를 유형화하여 자동 생성 로직(`src/services/aggro_generator.py`) 개선에 활용

---

## 0. TL;DR (한 문단 요약)

스레드의 쿠팡파트너스 글은 거의 예외 없이 **2단 구조**다. **1차 본문은 "광고가 아닌 척"** 하면서 수익 인증·호기심·스토리·긴급성으로 후킹만 하고 상품/링크를 절대 노출하지 않는다. **2차(자기 답글 = 연결 스레드 "2/2", 또는 고정 댓글)** 에서야 비로소 ① 법적 고지문구("쿠팡파트너스 활동의 일환으로 수수료를 제공받습니다") ② 가격중립 안심문구("구매가격에 영향 없음") ③ 유도 화살표(👇)와 한 줄 카피 ④ `link.coupang.com/a/...` 단축링크 ⑤ 알고리즘 부스팅 베이트("스+하+릿")를 배치한다. 이렇게 쪼개는 이유는 **스레드가 본문 외부링크에 도달 페널티를 주기 때문**이며, 1차로 도달을 극대화하고 2차로 전환을 일으키는 구조다. 단, 커뮤니티는 이미 이 수법에 피로감이 크다("비밀재료 그만해라", "광고같아서 차단").

---

## 1. 핵심 구조: 왜 1차 / 2차로 쪼개는가

| 단계 | 목적 | 들어가는 것 | 빠지는 것 |
|---|---|---|---|
| **1차 본문** | 도달(노출)·체류·저장·댓글 유도 | 강한 후킹(수익/호기심/스토리/긴급) | 외부링크 ❌, 광고 고지 ❌, 상품명 종종 ❌ |
| **2차 연결글/댓글** | 전환(클릭→구매) | 쿠팡 링크, 고지문구, 안심문구, 유도장치, 베이트 | — |

전략적 이유 3가지:
- **알고리즘 회피**: 스레드는 본문에 외부링크가 있으면 도달이 떨어진다. 1차를 "깨끗하게" 유지해 노출을 키운다.
- **광고 위장**: 의무 고지문구("수수료를 제공받습니다")조차 2차로 빼서, 1차는 자연스러운 일상글/정보글처럼 보이게 한다.
- **2단 퍼널**: 1차에서 저장·하트·리포스트로 도달을 부풀린 뒤, 관심 있는 사람만 2차 링크로 흘려보낸다.

## 3. 2차 댓글 상품 배치 방식 (4종 메커니즘)

### ① 연결 스레드(자기 답글) "2/2"에 쿠팡 링크 직접 — **가장 흔함**
1차 바로 아래 자기 답글로 이어 붙이는 방식. 표준 골격:
```
[쿠팡파트너스 고지문구]
[한 줄 카피 + 👇 / ⬇️ 유도]
link.coupang.com/a/XXXX
(쿠팡 상품 미리보기 카드 자동첨부)
[✅ 구매가격 영향 없음]
```
- 예시 `bebae_picks` (2/2): "이 게시물은 쿠팡파트너스 활동으로 … 내가 사용한 반칙 재료 ⬇️ `link.coupang.com/a/egP…` … ✅ 링크 구매 따른 구매자 가격 변동 없음" + 쿠팡카드("혼쯔유 코이다시")
- 예시 `da_mood.zip` (2/2): "목주름은 되돌리기 힘들다던데😭 나도 오늘부터 목까지 바르는 중👇 `link.coupang.com/a/efp…`"

### ② 프로필 링크 + 번호 검색
본문/댓글에 링크를 안 넣고 **프로필 링크트리**로 우회(외부링크 페널티 회피). 여러 상품을 번호로 관리.
- `ggdldmswjd25`: "해당 상품을 확인하시려면 **프로필링크 클릭 후 "001번/002번/003번"을 검색**해주세요!!" (상품마다 번호 시리즈)
- `vellichor.pogeun`: "해당 제품을 확인하시려면 프로필 링크를 클릭해주세요🙂"

### ③ 고정 댓글(핀)에 링크
- `richrich7821`: "구매처 안내: 영상 속 제품 정보 및 최저가 링크는 지금 바로 **[고정 댓글]** 또는 **[프로필 링크]**에서 확인하세요!"

### ④ 톡방·DM 유도 (수익 인증형 전용)
상품이 아니라 오픈채팅/코칭으로 보내는 퍼널.
- `_tsxiii`: "톡방 주소는 댓글에 남겨놨어!" → 첫 댓글에 오픈채팅 링크
- `hae_hyo_`: "스하리(스+하+리: 스크랩·하트·리포스트) 해주세요" → 도달 부풀린 뒤 DM 유도

## 4. 2차 공통 구성요소 (체크리스트)

| 요소 | 역할 | 실제 문구 예 |
|---|---|---|
| **의무 고지문구** | 법적 표기(공정위) | "이 포스팅/영상은 쿠팡파트너스 활동의 일환으로 일정액의 수수료를 제공받습니다" |
| **가격중립 안심문구** | 구매 저항 완화 | "구매자 가격 변동 없음", "스치니들 구매 가격에 영향이 전혀 없자라🩷" |
| **유도 장치** | 시선·클릭 유도 | 👇 ⬇️ "보러가기", "반칙 재료", "비밀재료" |
| **인게이지먼트 베이트** | 알고리즘 부스팅 | "스+하+릿 = 초고속 2배반사", "스할완", "반하리완료" |
| **단축 링크** | 전환 | `link.coupang.com/a/XXXX` (종종 2개 중복 배치로 클릭률↑) |
| **해시태그** | 검색 유입 | #선글라스 #파우치 #쿠팡파트너스 #네이버쇼핑 |

> 용어: **스하리/스할완/반하리** = 스레드의 "스크랩+하트+리포스트(+팔로우)" 품앗이 용어. 도달(조회수)을 끌어올리는 상호 부스팅 신호.

## 5. 상품 카테고리 ↔ 1차 후킹 매핑

| 카테고리 | 대표 후킹(1차) | 2차 배치 |
|---|---|---|
| 뷰티/안티에이징 (넥크림) | 연예인 동안 비결 (호기심) | 연결글 + 쿠팡링크 |
| 주방/레시피 (쯔유·우동) | "배달앱 켜기 전 이거 먼저" (실용) | 연결글 + 재료 링크 + 상품카드 |
| 패션/슈즈 (푸마·락피쉬) | 신상 대란·충동구매 (희소성/공감) | 연결글 + 쿠팡링크 |
| 향수 | 반전 유머 스토리 | 연결글 + 쿠팡링크 |
| 계절가전 (손선풍기) | 폭염 공포 + 한정수량 (긴급) | 고정댓글/프로필 |
| 운동/헬스 (골반) | "5~10분 몸짱" (실용) | 연결글 + 쿠팡링크 |
| 인테리어 소품 (공중부양 하우스) | "보면 힐링됨" (감성) | 연결글 + 쿠팡링크 + 상품카드 |
| 여행/숙박 | "국내 최장 수영장 숙소" (정보) | 연결글 + 쿠팡링크 |
| 정보성 영상(만화 등) | 영상 후킹 | 프로필링크 + 번호검색 |

어그로 강도와 신뢰도는 트레이드오프다. 과하면 차단·저품질 처리.

- **차단 트리거**: `danso.pohang` "쿠파스 달고 올리는 컨텐츠 진짜 믿음 안 가네ㅋㅋ" · `daily_joodi` "쿠파스 스레드로 하면 사람들이 싫어하고 아예 안 보거나 차단"
- **정보 게이팅 역효과**: `bn_love_00` "다 오픈해서 알려준 사람 링크는 들어가서 사는데, 안 알려주고 쿠파스만 걸면 차단해버림"
- **운영자도 인지**: `hz_labs` "쿠파스 글 조회수가 죽었다. 너무 광고같은 게 문제. **더 실제같은 말투를 도입해 자동화를 업데이트**했다."

시사점: **"광고 티"를 줄이는 자연스러운 1차 말투**가 도달·신뢰의 핵심 변수. 가격중립 안심문구·정보 선공개가 차단을 줄인다.

## 7. 자동 생성 로직(aggro_generator) 적용 제언

1. **1차/2차 분리 출력**을 기본 스키마로: `{hook_post, reply_with_link}` 형태.
2. **1차 후킹 유형 6종을 파라미터화**(A 수익인증 / B 호기심 / C 스토리·유머 / D 긴급·희소 / E 실용정보 / F 모집)하고 상품 카테고리별 가중치 매핑(§5).
3. **2차 템플릿화**: [고지문구] + [유도 카피 + 👇] + [링크 슬롯] + [가격중립 문구] (+ 옵션: 베이트, 해시태그).
4. **링크 배치 모드 3종 토글**: 연결글 직접 / 프로필링크+번호 / 고정댓글.
5. **"광고 티 감점" 가드레일**: 비밀재료·과장 이모지 도배 등 클리셰 사용 시 신뢰도 패널티 점수화(§6 반영). hz_labs 사례처럼 "실제 말투" 변형 슬롯 추가.
6. **고지문구 강제 삽입**(공정위 의무) — 2차에 항상 포함.
