## 0. 절대 원칙 (반드시 지킴)

1. **2단 구조 고정**: 모든 글은 `1차 본문(후킹)` + `2차 연결글/댓글(상품·링크)`로 분리한다.
2. **1차에는 링크·상품명·광고표기 금지** → 도달(노출) 극대화.
3. **2차에 쿠팡파트너스 고지문구 의무 삽입** (공정위 표시 규정).
4. **가격중립 안심문구 필수**: "구매가격에 영향 없음".
5. **허위 긴급/가격 조작 문구 금지**: "가격 고장났음", "품절 임박(거짓)" 등 ❌. 계절성 등 사실 기반 긴급만 허용.

## 1. 1차 본문 — 후킹 유형 6종

| 코드 | 유형 | 트리거 | 강도 |
|---|---|---|---|
| A | 수익 인증 | 부러움·욕망 | ★★★ |
| B | 호기심·티저 | 정보격차("뭔데?") | ★★★ |
| C | 스토리·유머 | 재미·공감 | ★★ |
| D | 긴급·희소(사실기반) | FOMO | ★★★ |
| E | 실용·정보 | 저장각·유용함 | ★★ |
| F | 멘토·모집 | 권위·소속감 | ★★ |

1차 구성: `훅 → 공감/결과 → 상품 티저(이름 숨김) → 전환 유도("뭔지는 댓글에 ⬇️")`

## 2. 2차 연결글/댓글 — 표준 골격

```
{쿠팡_고지문구}                         ← 의무
👇 {한줄_카피 + 상품명}
link.coupang.com/a/{제휴코드}
✅ {가격중립_문구}
{선택: 저장/스하리 유도}
```

배치 모드(택1): ① 자기답글 "2/2" 직접링크(기본) · ② 프로필링크+번호검색 · ③ 고정댓글 · ④ 톡방/DM(수익·모집형).

고지문구 표준안: `이 게시물은 쿠팡파트너스 활동의 일환으로 일정액의 수수료를 제공받습니다.`

## 4. 생성기 적용 메모

- 출력 스키마: `{ "hook_post": str, "reply_post": str, "hook_type": "A~F", "link_mode": "1|2|3|4" }`
- 상품 카테고리 → 후킹 유형 매핑은 분석 문서 §5 표 사용.
- '광고 티 감점' 가드레일: 비밀재료 클리셰·이모지 과다 도배 시 신뢰도 패널티(분석 §6 반영).
